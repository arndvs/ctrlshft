# working/

Cross-conversation working files. Plans, research docs, and runtime state live here.

This directory is tracked in git but its contents are gitignored. Only this README and `.gitignore` are committed.

## What goes here

- `*-plan.md` — Implementation plans for multi-conversation tasks
- `research.md` — Cached exploration results
- `active-client.md` — Current client context
- `compliance-log.md` — Compliance audit history

## Lifecycle

Plan files are created during work sessions and deleted when the work is complete. They are working documents, not permanent documentation.
